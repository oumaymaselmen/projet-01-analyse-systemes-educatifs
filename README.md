# Projet 01 - Analyse des donnees de systemes educatifs

> Formation Data Engineer - OpenClassrooms | Outils : Python, Pandas, JupyterLab, Poetry

## Objectif

Analyser le dataset EdStats de la Banque Mondiale pour explorer les indicateurs educatifs mondiaux : taux de scolarisation, niveaux d'education, disparites entre pays et regions.

## Competences travaillees

- Exploration et nettoyage de donnees volumineuses (CSV > 300 Mo)
- Analyse statistique avec Pandas
- Visualisation de donnees
- Gestion de l'environnement Python avec Poetry

## Contenu du repo

- Projet_2.ipynb : notebook principal d'analyse exploratoire
- pyproject.toml : configuration de l'environnement Poetry
- poetry.lock : versions exactes des dependances
- Selmen_Oumayma_2_presentation_102025.pptx : support de presentation

## Donnees

Dataset EdStats (Banque Mondiale) - non inclus dans ce repo en raison de la taille (> 300 Mo).
Source officielle : https://datacatalog.worldbank.org/search/dataset/0038480

## Lancer le projet

Installer les dependances :
poetry install

Lancer JupyterLab :
poetry run jupyter lab
